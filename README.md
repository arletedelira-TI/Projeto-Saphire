# 🏡 Saphire — Landing Page Imobiliária

Projeto desenvolvido durante o curso **Transforme-se** da **Serasa Experian**, em parceria com o **Instituto PROA**.

O objetivo principal foi praticar conceitos fundamentais de **HTML5** e **CSS3**, criando uma landing page moderna para uma empresa fictícia do setor imobiliário.

---

## 📸 Preview

A interface apresenta uma proposta clean e moderna, com foco em:

- Destaque visual para o produto (imóvel)
- Hierarquia de informações
- Navegação simples e intuitiva

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

---

## 🎯 Objetivos do projeto

- Praticar estruturação semântica com HTML
- Trabalhar estilização com CSS
- Desenvolver noções de layout (alinhamento, espaçamento, responsividade básica)
- Criar uma interface visual agradável e funcional
